# Security

TraceDeck FE does not use accounts, cloud services, telemetry, game injection or game-memory access.

If you find a security issue, open a GitHub issue with a minimal, non-sensitive summary. Do not include credentials, private projects, personal reference images or exploit details in a public report. A maintainer can then determine an appropriate way to continue the discussion.

Only the latest public release is expected to receive security fixes. The v1.0.0 executable is unsigned, so verify release assets and the published SHA-256 value before running them.
