# TraceDeck FE v1.0.0

First public release of TraceDeck FE.

## Highlights

- Target-relative reference overlay for manual vinyl and decal tracing
- Move, scale, rotate, flip, opacity and click-through lock controls
- Grayscale, contrast, grid and center-guide assistance
- Original-pixel color picker with HEX, RGB and Forza HSB output
- Named and automatically generated palettes
- Self-contained `.TDFE` projects with embedded reference data
- Session Undo/Redo, autosave and recovery
- Configurable shortcuts and English/Korean UI
- Self-contained single-file Windows x64 portable build

## Download

Attach this asset to the GitHub release:

`TraceDeckFE-v1.0.0-win-x64-portable.zip`

## Requirements

- Windows 10 or Windows 11, x64
- Forza Horizon 6 in Windowed or Borderless mode is recommended
- No separate .NET runtime installation is required for the portable build

## Notes

- TraceDeck FE is unsigned; Windows reputation protection may display a warning.
- Exclusive fullscreen can hide a normal desktop overlay.
- TraceDeck FE is an unofficial community tool and is not affiliated with or endorsed by Microsoft, Xbox, Playground Games or the Forza franchise.
