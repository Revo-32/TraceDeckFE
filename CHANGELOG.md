# Changelog

All notable changes to TraceDeck FE will be documented in this file. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-29

### Added

- Initial public release for Windows 10/11 x64.
- Target-relative reference overlay with move, scale, rotation, flips, opacity and click-through locking.
- Grayscale, contrast, grid and center-guide assistance.
- Original-reference color picker with HEX, RGB and Forza HSB output.
- Named and automatically generated palettes.
- Self-contained `.TDFE` projects with embedded reference data.
- Session Undo/Redo, autosave, recovery and configurable shortcuts.
- English and Korean user interface.
- Self-contained single-file portable distribution and Korean PDF user guide.
